# M00: Repository audit and baseline

These scenarios are product test designs, not executed tests.

## AUD-001: Preserve the existing checkout

Given: The repository contains uncommitted user changes.

When: The audit and first test setup run.

Then: Unrelated file bytes and Git state remain unchanged.

Required platform roles: host.

## AUD-002: Honor the compiler pin

Given: The local wrapper reports the supplied compiler version.

When: The agent starts development.

Then: All Windows compiler calls use the wrapper and no pin changes occur.

Required platform roles: host.

## AUD-003: Reject pin mismatch

Given: A fixture wrapper reports a different compiler version.

When: The baseline checks its identity.

Then: The check fails explicitly instead of silently selecting global Zig.

Required platform roles: host.

## AUD-004: Map existing implementation

Given: The build files and source already contain code.

When: The audit inventories modules and tests.

Then: The report identifies reusable behavior and no replacement scaffold appears.

Required platform roles: host.

## AUD-005: Record baseline failures

Given: An existing test fails before edits.

When: The baseline runs.

Then: The report preserves the real exit code and separates that failure from new changes.

Required platform roles: host.

## AUD-006: Discover host capabilities

Given: The host has a specific OS, architecture, and SDK set.

When: The capability inventory runs.

Then: The report contains observed values and labels unavailable targets honestly.

Required platform roles: host.

## AUD-007: Inspect dependency provenance

Given: The build uses pinned external inputs.

When: The audit inspects bootstrap and dependency paths.

Then: The report records verification and license gaps without invented digests.

Required platform roles: host.

## AUD-008: Preserve legacy WSL state

Given: The user has existing WSL source and a custom kernel.

When: Case-zero preparation runs.

Then: No WSL disk, source directory, kernel, or host security setting changes.

Required platform roles: host.
