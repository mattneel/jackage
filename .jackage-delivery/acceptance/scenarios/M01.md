# M01: CLI foundation and diagnostics

These scenarios are product test designs, not executed tests.

## CLI-001: Report real version

Given: A built client exists.

When: The version command runs.

Then: It reports the product build identity and exits successfully.

Required platform roles: host.

## CLI-002: Provide usable help

Given: The parser has all registered commands.

When: Root and command help run.

Then: Help reflects actual command metadata and contains no fictitious implemented features.

Required platform roles: host.

## CLI-003: Separate JSON output

Given: Structured output is selected.

When: Success and failure commands run.

Then: Stdout contains only valid documented JSON or JSON-line events.

Required platform roles: host.

## CLI-004: Reject invalid syntax

Given: Unknown flags and malformed arguments exist.

When: The parser receives them.

Then: It returns a stable usage error without partial side effects.

Required platform roles: host.

## CLI-005: Preserve argument boundaries

Given: Arguments contain spaces, quotes, Unicode, and shell metacharacters.

When: The CLI dispatches a task.

Then: The receiver observes the exact argv values without implicit shell evaluation.

Required platform roles: host.

## CLI-006: Avoid implicit prompts

Given: Stdin is noninteractive and trust is missing.

When: A command needs authorization.

Then: It returns an explicit policy error instead of waiting or autoapproving.

Required platform roles: host.

## CLI-007: Initialize safely

Given: Project declarations already exist.

When: The init command runs.

Then: Existing files remain unchanged and conflicts are reported.

Required platform roles: host.

## CLI-008: Diagnose honestly

Given: The native executor lacks a strict capability.

When: Doctor reports capabilities.

Then: The missing enforcement appears explicitly and cannot become release support.

Required platform roles: host.

## CLI-009: Respect cancellation

Given: A long client operation is active.

When: The user cancels it.

Then: The CLI stops cleanly and emits a final cancellation result.

Required platform roles: host.

## CLI-010: Keep secrets out of errors

Given: A fixture URL and environment contain token-shaped secrets.

When: Commands fail at each boundary.

Then: Public diagnostics and structured output omit the secret values.

Required platform roles: host.
