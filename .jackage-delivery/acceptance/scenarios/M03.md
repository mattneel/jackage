# M03: Native action execution

These scenarios are product test designs, not executed tests.

## EXE-001: Execute exact argv

Given: A declared tool and argument array exist.

When: The native executor launches the tool.

Then: The tool receives exact arguments and a recorded exit result.

Required platform roles: host.

## EXE-002: Clear ambient environment

Given: The host environment contains undeclared variables.

When: A clean action starts.

Then: The process receives only the declared environment and documented platform minimum.

Required platform roles: host.

## EXE-003: Collect only declared outputs

Given: The process writes declared and undeclared paths.

When: Output collection runs.

Then: Only declared valid outputs become artifacts.

Required platform roles: host.

## EXE-004: Reject output escape

Given: A process creates a symlink or reparse escape at an output path.

When: The collector traverses outputs.

Then: It rejects the escape and publishes no escaped data.

Required platform roles: host.

## EXE-005: Retain action failure

Given: A process exits with a nonzero status.

When: The executor returns.

Then: It records action failure and excludes partial output from successful cache results.

Required platform roles: host.

## EXE-006: Distinguish launch failure

Given: The declared executable cannot launch.

When: The executor starts the action.

Then: It returns infrastructure or launch failure distinct from process exit.

Required platform roles: host.

## EXE-007: Cancel descendants

Given: A process creates children and grandchildren.

When: The controller cancels or times out the action.

Then: The owned process tree stops before its leases are released.

Required platform roles: host.

## EXE-008: Report native limitations

Given: The native backend cannot prevent arbitrary file access.

When: A strict action selects it.

Then: Policy matching refuses the action rather than downgrading it.

Required platform roles: host.

## EXE-009: Bound diagnostics

Given: A process emits excessive stdout and stderr.

When: The configured log budget is reached.

Then: The system applies its declared limit without deadlock or unbounded memory use.

Required platform roles: host.

## EXE-010: Reconcile controller failure

Given: The controller stops while an action continues.

When: A new controller starts.

Then: It reconciles actual process and lease state before retry or collection.

Required platform roles: host.
