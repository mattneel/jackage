# M06: Profiles and transient execution

These scenarios are product test designs, not executed tests.

## PROFILE-001: Install a closure

Given: A trusted local package and dependencies exist.

When: Install completes.

Then: A valid profile generation references the complete runtime closure.

Required platform roles: host.

## PROFILE-002: Activate atomically

Given: Installation stops at every activation transaction point.

When: The client restarts.

Then: Either the old or complete new generation remains selected.

Required platform roles: host.

## PROFILE-003: Rollback a generation

Given: Two valid generations exist.

When: Rollback selects the earlier generation.

Then: Commands resolve to the earlier package closure.

Required platform roles: host.

## PROFILE-004: Remove references safely

Given: A package is removed from a profile.

When: The generation changes.

Then: User source remains untouched and shared dependencies stay reachable.

Required platform roles: host.

## PROFILE-005: Handle executable collision

Given: Two selected packages expose the same command name.

When: The profile is constructed.

Then: The documented conflict policy prevents silent ambiguous replacement.

Required platform roles: host.

## PROFILE-006: Preserve active executable

Given: A prior generation has an active process or open executable.

When: Upgrade and collection run.

Then: The active closure remains usable until its lease ends.

Required platform roles: host.

## PROFILE-007: Run transiently

Given: A verified package is available.

When: jckgx executes its default entry point.

Then: The installed profile and global PATH remain unchanged.

Required platform roles: host.

## PROFILE-008: Forward runner arguments

Given: The package receives help flags, separators, and quoted arguments.

When: jckgx dispatches it.

Then: Its argv matches the documented package-argument grammar.

Required platform roles: host.

## PROFILE-009: Preserve runner exit

Given: A package exits unsuccessfully.

When: jckgx returns.

Then: The caller receives the documented program status and structured result.

Required platform roles: host.

## PROFILE-010: Lease concurrent runners

Given: Multiple jckgx instances share an artifact.

When: One exits while collection runs.

Then: Remaining executions retain the full closure without writable workspace sharing.

Required platform roles: host.
