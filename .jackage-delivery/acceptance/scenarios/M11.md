# M11: Native platform matrix and packages

These scenarios are product test designs, not executed tests.

## PLAT-001: Run Windows x86_64

Given: A native Windows x86_64 client exists.

When: Install, rollback, run, and build smoke tests execute.

Then: Actual native results pass with platform details.

Required platform roles: windows-x86_64.

## PLAT-002: Run Windows aarch64

Given: A native Windows aarch64 client exists.

When: The same smoke tests execute.

Then: Actual native results pass without a cross-compile-only claim.

Required platform roles: windows-aarch64.

## PLAT-003: Run Linux x86_64

Given: A native Linux x86_64 client exists.

When: The same smoke tests and strict checks execute.

Then: Actual native results pass with the declared ABI.

Required platform roles: linux-x86_64.

## PLAT-004: Run Linux aarch64

Given: A native Linux aarch64 client exists.

When: The same smoke tests and strict checks execute.

Then: Actual native results pass with platform details.

Required platform roles: linux-aarch64.

## PLAT-005: Run macOS x86_64

Given: A native macOS x86_64 client and authorized SDK exist.

When: Native smoke tests execute.

Then: Results and SDK boundaries are recorded.

Required platform roles: macos-x86_64.

## PLAT-006: Run macOS aarch64

Given: A native macOS aarch64 client and authorized SDK exist.

When: Native smoke tests execute.

Then: Results and SDK boundaries are recorded.

Required platform roles: macos-aarch64.

## PLAT-007: Validate Windows filesystem

Given: A disposable tree contains long paths, Unicode, reparse points, and locked executables.

When: Native store and profile tests run.

Then: Supported cases work and unsafe cases fail explicitly.

Required platform roles: windows-x86_64.

## PLAT-008: Validate Debian package

Given: A Debian package backend produces Jackage.

When: A disposable Debian environment inspects and installs it.

Then: Metadata, executable, dependency, and uninstall smoke tests pass.

Required platform roles: linux-x86_64.

## PLAT-009: Validate RPM package

Given: An RPM backend produces Jackage.

When: A disposable RPM environment inspects and installs it.

Then: Native package smoke tests pass.

Required platform roles: linux-x86_64.

## PLAT-010: Validate MSIX

Given: A Windows package backend produces an MSIX fixture.

When: Native tools validate it and authorized disposable installation runs.

Then: Manifest, architecture, and payload checks pass.

Required platform roles: windows-x86_64.

## PLAT-011: Validate macOS package

Given: A macOS backend produces an unsigned test package.

When: Native tools inspect it and an authorized disposable installation runs.

Then: Package layout and executable checks pass.

Required platform roles: macos-aarch64.

## PLAT-012: Declare SDK perimeter

Given: A release action requires a proprietary SDK.

When: The dependency closure and publication plan are validated.

Then: The SDK boundary and redistribution policy are explicit.

Required platform roles: portable.
