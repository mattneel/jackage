# M12: Workspace, cache, and reclaim lifecycle

These scenarios are product test designs, not executed tests.

## SPACE-001: Protect user source

Given: A disposable primary checkout and managed store exist.

When: GC and cache eviction run.

Then: Source bytes and uncommitted files remain untouched.

Required platform roles: portable.

## SPACE-002: Trace roots

Given: Profiles, pins, runtime references, and leases retain objects.

When: Collection computes reachability.

Then: Every retained object has an attributable root or lease.

Required platform roles: portable.

## SPACE-003: Race leases safely

Given: A new action lease races candidate selection.

When: GC applies deletion.

Then: The action retains access or retries safely before execution.

Required platform roles: portable.

## SPACE-004: Recover stale lease

Given: A controller crashes and its PID is reused.

When: Lease recovery runs.

Then: It does not delete active work through a naive PID or time check.

Required platform roles: portable.

## SPACE-005: Bound caches

Given: Multiple project caches exceed the policy ceiling.

When: Eviction runs with active leases and pins.

Then: Eligible caches shrink and unsatisfied budgets remain explicit.

Required platform roles: portable.

## SPACE-006: Separate platform caches

Given: Windows and Linux build the same project.

When: Workspace synchronization runs.

Then: Neither platform's compiler cache copies into the other's source tree.

Required platform roles: portable.

## SPACE-007: Snapshot stable bytes

Given: A source file changes during capture.

When: Snapshot construction runs.

Then: It retries or reports instability rather than committing inconsistent metadata.

Required platform roles: portable.

## SPACE-008: Preserve source manifest

Given: A checkout contains ignored output, generated required source, and secrets.

When: A preview and snapshot run.

Then: Explicit manifest policy includes required input and excludes prohibited data.

Required platform roles: portable.

## SPACE-009: Protect host edits

Given: A guest exports edits while the host changed the same file.

When: Reconciliation runs.

Then: It reports divergence and never silently overwrites host source.

Required platform roles: portable.

## SPACE-010: Deliver watcher events

Given: An editor performs write, atomic replacement, rename, and delete operations.

When: Guest updates apply on a native Linux workspace.

Then: Real watcher tests observe the documented changes.

Required platform roles: linux-x86_64.

## SPACE-011: Measure native execution

Given: Fixed cold and warm workloads exist.

When: Native-baseline and backend benchmarks run.

Then: Results separate transfer and meet the declared execution budget or fail.

Required platform roles: host.

## SPACE-012: Measure reclaim

Given: A disposable VM disk grows with known cache data.

When: Deletion, trim, and supported compaction run.

Then: The report compares actual host allocation and reports unsupported reclaim honestly.

Required platform roles: host.
