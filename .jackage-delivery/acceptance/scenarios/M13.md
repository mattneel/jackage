# M13: External backend contracts

These scenarios are product test designs, not executed tests.

## PLUGIN-001: Negotiate versions

Given: Core and plugin offer incompatible major versions.

When: Handshake runs.

Then: No action starts and a version error results.

Required platform roles: portable.

## PLUGIN-002: Bound frames

Given: A plugin sends oversized or malformed JSON frames.

When: The core reads its stream.

Then: It rejects the frame without unbounded allocation or partial dispatch.

Required platform roles: portable.

## PLUGIN-003: Separate plugin diagnostics

Given: A plugin logs diagnostic output.

When: Protocol exchange runs.

Then: Diagnostics remain off protocol stdout and stay within limits.

Required platform roles: portable.

## PLUGIN-004: Apply backpressure

Given: A plugin produces events faster than the consumer reads.

When: A long action runs.

Then: Bounded buffers preserve protocol progress or trigger a defined limit.

Required platform roles: portable.

## PLUGIN-005: Cancel external action

Given: A plugin owns a process tree.

When: Core cancellation arrives.

Then: The action reaches a reconciled terminal state before lease release.

Required platform roles: portable.

## PLUGIN-006: Interchange executors

Given: Two independent executor implementations support a contract subset.

When: The same conformance actions run.

Then: Both satisfy identical behavior and report their distinct limitations.

Required platform roles: portable.

## PLUGIN-007: Interchange package plugins

Given: Two independent package implementations describe package actions.

When: Their common contract suite runs.

Then: Plans remain declarative and no host callback escapes policy.

Required platform roles: portable.

## PLUGIN-008: Interchange repositories

Given: Two transport plugins serve equivalent signed metadata and assets.

When: Resolution and fetch run.

Then: Core trust behavior is identical across transports.

Required platform roles: portable.

## PLUGIN-009: Constrain plugin authority

Given: A plugin requests undeclared filesystem or credential authority.

When: Core policy evaluates the request.

Then: The request fails without automatic permission expansion.

Required platform roles: portable.

## PLUGIN-010: Recover plugin crash

Given: A plugin terminates during an action.

When: Core recovery runs.

Then: Action status remains unknown until reconciled and no false success is cached.

Required platform roles: portable.
