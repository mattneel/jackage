# M15: Development and release images

These scenarios are product test designs, not executed tests.

## IMAGE-001: Assemble dev environment

Given: The Jackage environment declaration is locked.

When: An OCI development image is built.

Then: It contains declared tools and no host credentials.

Required platform roles: portable.

## IMAGE-002: Run development image

Given: A real compatible runtime is available.

When: The image builds and tests a Jackage fixture.

Then: The declared tools execute on native guest storage.

Required platform roles: linux-x86_64.

## IMAGE-003: Assemble release image

Given: A Jackage runtime closure is selected.

When: The release image backend runs.

Then: Build-only tools and mutable caches remain outside the payload.

Required platform roles: portable.

## IMAGE-004: Build root filesystem

Given: A locked runtime manifest exists.

When: The rootfs exporter runs.

Then: The exported filesystem passes closure and entry-point tests.

Required platform roles: linux-x86_64.

## IMAGE-005: Validate ext4 image

Given: The backend creates a disposable ext4 image.

When: Filesystem inspection and mount tests run.

Then: File contents and metadata satisfy the declared payload contract.

Required platform roles: linux-x86_64.

## IMAGE-006: Validate VHDX container

Given: A VHDX contains a declared guest filesystem.

When: A real compatible host attaches it.

Then: The guest payload is valid and the container lifecycle is safe.

Required platform roles: windows-x86_64.

## IMAGE-007: Report image reproducibility

Given: Repeated image builds contain variable wrapper fields.

When: Reproduction compares declared artifacts.

Then: The report distinguishes payload equality from whole-image byte equality.

Required platform roles: portable.

## IMAGE-008: Exclude user state

Given: A developer workspace contains secrets, caches, and Git metadata.

When: Images build from their manifests.

Then: Prohibited user state is absent from every layer and image payload.

Required platform roles: portable.
