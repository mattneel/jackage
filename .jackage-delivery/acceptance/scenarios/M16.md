# M16: Agent-native factory and migration

These scenarios are product test designs, not executed tests.

## FACTORY-001: Use one human-agent contract

Given: A human and OMP select the same locked task.

When: Each requests execution.

Then: The same plan, policy, and artifact identities govern both paths.

Required platform roles: portable.

## FACTORY-002: Expose structured progress

Given: OMP runs a long task through the documented interface.

When: Progress and failure events arrive.

Then: The agent can interpret schema-valid events without terminal scraping.

Required platform roles: portable.

## FACTORY-003: Preserve agent secrets

Given: OMP has provider credentials on the host.

When: It launches a strict build.

Then: The build cannot read those credentials or inherit provider authority.

Required platform roles: portable.

## FACTORY-004: Isolate parallel agents

Given: Two work units start from a shared source baseline.

When: Agents edit and build concurrently.

Then: They use distinct mutable workspaces and explicit integration.

Required platform roles: portable.

## FACTORY-005: Migrate a legacy fixture

Given: A disposable project has separate Windows and Linux caches.

When: The migration guide runs.

Then: Source survives and managed cache ownership becomes measurable.

Required platform roles: portable.

## FACTORY-006: Rollback migration

Given: The migrated disposable project retains a previous workflow.

When: The rollback guide runs.

Then: The project returns to the previous workflow without source loss.

Required platform roles: portable.

## FACTORY-007: Demonstrate full pipeline

Given: Jackage source and all authorized local inputs exist.

When: Build, test, package, local publish, install, run, rollback, and collect execute.

Then: Every stage produces actual evidence through the public interfaces.

Required platform roles: host.

## FACTORY-008: Resume agent work

Given: An agent stops after a partial milestone.

When: A new OMP session reads the handoff.

Then: It resumes the exact next test without repeating a destructive setup.

Required platform roles: host.
